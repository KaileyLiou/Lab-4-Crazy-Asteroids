# Lab 4: Crazy Asteroids

A Pygame project created for A.I. for Game Programming class to practice vectors and collision physics.

This project displays six asteroids moving across the screen. Each asteroid has a randomized starting position, movement vector, and size.

The asteroids wrap around the edges of the screen and interact with one another when they collide.

## Features

- Six moving asteroids
- Randomized asteroid positions
- Randomized movement vectors
- Asteroids with different sizes
- Screen wrapping
- Asteroid-to-asteroid collision detection
- Collision normals used to calculate bounces
- Mass-based velocity changes
