# Lab 4: Crazy Asteroids

A Pygame project created for my A.I. for Game Programming class to practice vectors and collision physics.

This project displays six asteroids moving across the screen. Each asteroid has a randomized starting position, movement vector, and size. The asteroids wrap around the edges of the screen and bounce off one another when they collide.

## Features

- Six moving asteroids with random sizes, positions, and velocities
- Screen wrapping
- Asteroid-to-asteroid collision detection
- Collision normals and mass-based velocity changes
